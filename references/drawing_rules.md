# 氨基酸 Fischer 投影式绘制规则

## 1. 默认表示范围

本技能默认绘制蛋白质中20种标准α-氨基酸的两性离子形式。主链羧基可写为 `COO⁻`，氨基写为 `H₃N⁺`；脯氨酸环上氮写为 `H₂N⁺`。若用户指定特定 pH 或非离子形式，应依据该条件调整质子化状态并在图注中说明。

## 2. Fischer 投影与立体化学

- L-α-氨基酸的标准 Fischer 投影：`COO⁻` 在上、侧链 R 在下、`H₃N⁺` 在左、H 在右。
- Fischer 投影的横键朝向观察者，竖键背向观察者。不能仅凭页面左右互换而声称构型不变。
- 甘氨酸没有手性中心，但保持同一主链版式以便教学比较。
- L-半胱氨酸按 Fischer 位置仍属于 L 系列；其 CIP 构型为 R 不构成矛盾。
- L-异亮氨酸和 L-苏氨酸有第二手性中心。绘图前核对天然蛋白质常见立体异构体，不得仅凭二维美观翻转支链交叉。
- 脯氨酸采用闭合五元环投影，α-C、羧基、H、质子化环氮与三个 `CH₂` 的连接必须闭合且无交叉误连。

## 3. 重原子与键的表示

- 除芳香环碳顶点可按骨架式省略 C 外，所有非氢原子必须显示，所有非氢原子之间的键必须画出。
- `CH`、`CH₂`、`CH₃` 中，键必须连接 C，不能连接 H 或下标数字。
- 只有与单个氢原子相连的键可省略；不得用字符间距暗示 C—C、C—N、C—O 或 C—S 键。
- 羧酸盐可缩写为 `COO⁻`。若展开绘制，应显示一个 C=O、一个 C—O⁻，并注意共振说明。
- 酰胺必须显示 C=O 与 C—NH₂；精氨酸胍基必须显示规定的 C=N 双键及正式电荷；苯环、吲哚环、咪唑环的双键或芳香键必须完整。

### 3.1 Fischer 投影中组合标签的轴向定位

- 竖轴上的 `CHO`、`COOH` 和 `CH₂OH` 均通过其中的 C 与手性中心相连。必须把该 C 的字面中心放在竖键轴线上；禁止把整个 `CHO`、`COOH` 或 `CH₂OH` 文本块整体居中于竖轴，因为这样会使键在视觉上落到 H、O、下标或字符间隙。
- 推荐把组合标签保持为同一文本流，并将其起点设置为“竖轴位置减去首个 C 的半个字面宽度”；随后紧接 H、O、下标等字符。若拆分绘制 C 与其余字符，二者必须保持正常字距，不能呈现为 `C HO`、`C OOH` 或 `C H₂OH`。
- 横轴左侧的 `HO—` 与 `H₂N—` 应分别以 O、N 靠近中心并连接横键；横轴右侧的 `—OH` 与 `—NH₂` 应分别以 O、N 靠近中心。字符书写顺序应服从“成键原子靠近键端”，而不是机械地把标签整体居中。
- 对其他方向使用相同原则。例如末端甲基的键从右侧离开时可写 `H₃C—`，从左侧进入时可写 `—CH₃`，确保键始终接在 C 上。

## 5. 默认分组组图

1. 甘氨酸、丙氨酸、缬氨酸、亮氨酸、异亮氨酸。
2. 天冬氨酸、谷氨酸、赖氨酸、精氨酸、丝氨酸、苏氨酸。
3. 半胱氨酸、甲硫氨酸、天冬酰胺、谷氨酰胺。
4. 苯丙氨酸、色氨酸、酪氨酸。
5. 组氨酸、脯氨酸。

每个氨基酸标签采用“中文名（三字母缩写，单字母缩写）”。同组结构置于一排；结构之间留足空间，但不以拉长化学键或改变构型来迁就排版。

## 6. 字体和版式

- 化学字符、数字、正负号及英文缩写：Times New Roman。
- 中文名称：宋体。括号内英文缩写仍用 Times New Roman。
- 化学键使用正常线宽，不因提高分辨率而人为加粗。
- 主字母 C 与 H 必须共享字体文件、字号和基线。Times New Roman 的 C 具有曲线过冲，视觉上可能比 H 高约一个像素；这是字体设计，不应通过错开基线补偿。
- 下标使用较小字号并下沉；上标电荷使用较小字号并上移。
- 组图同时保留 SVG 矢量文件和300 dpi PNG。SVG 用于教材排版与后续编辑，PNG 用于审阅和快速插入。

## 7. 必做质检

逐个结构检查：

1. α-C 四个取代基及 Fischer 方位是否正确。
2. 每个非环脂肪族 C 是否可见；每根重原子键是否真正接到 C/N/O/S。
3. `CHO`、`COOH`、`CH₂OH` 等竖轴标签的成键 C 是否位于键轴上；左右组合标签中靠近键端的是否为实际成键原子。
4. CHₙ 的 C 与 H 是否等大、同基线，下标是否独立且不遮挡键。
5. 双键、芳香环、杂环 N、正式电荷与质子数是否正确。
6. 缬氨酸、亮氨酸、异亮氨酸等支链的中心 C 是否同时连接所有相邻重原子。
7. 色氨酸是否为吲哚-3-基，组氨酸是否为咪唑-4(5)-基。
8. 图注中英文是否分别使用规定字体，缩写与单字母代码是否正确。
9. 组图裁切、间距和缩放是否一致，任何键是否因白色遮罩而变短或断续。

若任一项失败，应修改结构源或排版源并重新导出所有受影响的单图和组图，不能在最终 PNG 上用临时文字补丁掩盖问题。
