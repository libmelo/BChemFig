# 教材用氨基酸反应式绘制规则

## 1. 适用范围与默认输出

本规则适用于中文食品生物化学、生物化学教材中的氨基酸典型反应式，包括投影式、半展开式与骨架式组合。默认输出 SVG 矢量文件和 300 dpi PNG，并保留白底版本；需要与 Word 页面底色融合时，同时输出透明背景版本。

不得把参考图当作绝对正确的结构源。先确认反应物、产物、官能团变化、条件、价态和原子连接，再按统一版式重绘。具体分子可用 RDKit 等专业化学工具核对；含 `R`、`R′` 的通式须人工逐键核验。

## 2. 化学连接是最高优先级

- 除芳香环碳顶点按骨架式允许省略外，所有关键非氢原子及其相互连接必须可见。
- 键必须终止在实际成键原子上。`CH`、`CH₂`、`CH₃`、`COOH`、`NH₂` 等组合标签中，C—C 键接 C，C—N 键接 N，C—O 键接 O；不得把键画到 H、下标数字或整个文字块的视觉中心。
- 当组合标签会导致误接时，将成键原子与其余字符分开排版，例如先把 `C` 放在键轴线上，再在右侧补 `OOH`。
- 双键由两条等长、等粗、平行线构成；羰基、硫羰基、亚胺和芳香双键不得退化为单键。
- 环系必须闭合，环内杂原子、羰基、硫羰基和取代位置必须准确。不得为追求对称而改变原子连接或环大小。
- 投影式若表达立体化学，必须保持 Fischer 投影约定；若仅用于通式教学，也不得通过左右互换造成未说明的构型变化。

## 3. 反应内容与箭头

- 反应箭头应短而清楚，靠近反应物和产物，避免用长箭头填充空白。正文常用结构字高约 50–58 px 时，单向箭头主体通常控制在约 85–130 px；根据结构密度微调。
- 箭头与式内空白同步收紧，结构之间保持可读但不形成大段留白。
- 条件置于箭头正上方，必要的溶剂或副条件置于下方；中文用宋体，化学式用 Times New Roman。不要重复写正文已说明且对理解无帮助的条件。
- 可逆反应用两条短、平行、方向相反的箭头。脱水方向标 `−H₂O`，水解方向标 `+H₂O` 时，两标注分别与对应箭头对齐。
- 不凭参考图机械添加游离 `H⁺`。只有当它是反应物、产物或必须展示的催化条件时才标出。
- 反应物、产物、副产物之间的加号与主式垂直居中；气体可用 `↑`，但整套图的表示方式必须一致。

## 4. 字体、变量和上下标

- 化学元素、化学式、数字、英文缩写和反应条件中的拉丁字符使用 Times New Roman。
- 中文名称和中文条件使用宋体；图下注释可适当加粗，以便在教材缩印后仍清晰。
- 元素符号用正体；本教材通式中的取代基标签 `R`、`R′`、保护基标签 `Y` 也统一使用 Times New Roman 正体，不与斜体混用。
- `R′` 不应依赖字体的整串字形自动定位。将正体 `R` 与较小的撇号分别绘制，撇号置于 R 的右上方；同一组图中其水平偏移、高度和字号比例保持一致。
- `R′X`、`R′HN` 等组合中，撇号仍只修饰 R；字符间距须保证 `X`、H、N 不被误读为上标内容。`R′HN—` 的连接键必须终止于 N。
- 下标和上标分别以较小字号独立放置，不用基线全字号数字代替。主字母 C、H、N、O、S 使用同一文字引擎、字体文件、字号和基线。

## 5. 键线、投影式和空间控制

- 化学键采用正常线宽，不因放大结构或提高分辨率而额外加粗。结构字高约 50–58 px 时，主键线宽通常约 3–4 px。
- 投影式键应短，键端与字符留出一致的光学间隙。不得让键穿入字形，也不得因遮罩过大造成断键。
- 同一投影式的上下键、左右键长度分别一致；中心 C 与横、竖键严格共轴。
- 结构式内部优先压缩无信息空白，而不是压缩字符或扭曲键角。不同反应式之间保持相近的视觉密度。
- 苯环和杂环采用规则几何形状；芳香双键缩进量一致。环上取代键沿顶点方向延伸并连接正确顶点。
- PTH-氨基酸五元环中，相邻的 N—C 与 C—C 边可画成竖直、彼此平行的边，以稳定版式；羰基 C=O、硫羰基 C=S、环内 N—H、α-C 上的 H 和 R 均须连接到相应原子。α-C 已单独显示 H 时标为 `C`，不得写成 `CH`。

## 6. 五类标准反应的专项核对

### 6.1 与亚硝酸反应

α-氨基酸的 α-氨基转为羟基，产物为 α-羟基酸，并生成 N₂ 和 H₂O。若教材正文已说明机理，通式中不额外标游离 H⁺。

### 6.2 N-酰基化反应

氨基酸氨基的一个 H 被酰基取代。通式 `H₂N—CH(R)—COOH + R′X → R′HN—CH(R)—COOH + HX` 中，产物左侧键接 N；`R′` 的撇号须使用统一上标定位。

### 6.3 DNFB 反应

1-氟-2,4-二硝基苯的 F 被氨基酸氨基取代，生成黄色 DNP-氨基酸和 HF。核对两个硝基的位置、芳环双键、N—芳环键及 N—α-C 键。

### 6.4 Edman 降解

异硫氰酸苯酯与 N 端氨基酸在弱碱中形成 PTC-氨基酸，酸处理后形成 PTH-氨基酸。重点核对 `Ph—N=C=S`、PTC 的硫脲连接和 PTH 五元环；PTH 的最右侧手性中心为显式 `C`，其 H 与 R 另行连接。

### 6.5 希夫碱形成

醛与氨基酸氨基形成 C=N，正向为脱水，逆向为加水。醛和产物中的 `R′` 应采用完全相同的上标位置，醛羰基与产物亚胺双键必须保持平行双线。

## 7. 必做质检

逐个反应式在原始分辨率下检查：

1. 反应物、产物、副产物和条件是否符合反应事实。
2. 每根重原子键是否连接到正确的 C、N、O 或 S，而非 H 或文本中心。
3. 所有双键、芳香键、环闭合、杂原子、正式电荷和质子数是否正确。
4. 投影式的中心 C、横键、竖键以及取代基方位是否一致。
5. `R`、`R′`、上下标和电荷是否使用统一字体、字号比例与基线；所有 `R′` 撇号是否对齐。
6. 箭头是否足够短、条件是否居中、结构之间是否紧凑且不拥挤。
7. 中文是否为宋体，化学字符和英文是否为 Times New Roman，标题或图下注释在缩印后是否清晰。
8. PTH、DNFB 等复杂结构是否与可解析分子图或权威资料逐原子对应。
9. 白底与透明背景版本是否内容完全一致，PNG 是否带 300 dpi 元数据，SVG 是否无裁切。

任一检查失败时，应修改矢量或程序源并重新生成所有受影响版本，不得只在最终 PNG 上覆盖文字或局部补线。
